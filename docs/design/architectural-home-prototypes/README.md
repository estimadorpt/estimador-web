# Architectural homepage prototypes — 12 September 2026

Three visual explorations, generated with the built-in image tool. Prompts are in prompts.json. No website changes.

1. **Warm evolution** — closest to current illustrations, sage and clay in place of the four-pastel mix. Still detailed; intended as a continuity option.
2. **Architectural mosaic** — mineral blue, sage and apricot, with arches and room shapes connecting the illustrations to the geometric identity. Recommended for further exploration.
3. **Small world** — axonometric neighbourhood and buildings, strongest sense of an explorable world; more detailed than requested and would need simplification at small sizes.

These are static art-direction prototypes, not implementation specifications. Retain the real existing logo, font and live data. The generated logo, invented search/selector controls, slogans, illustrative building labels and added copy are not approved. In particular, do not turn election forecasts into results, advertise paused economy data as fresh, or copy “pessoas reais” from the decorative market sign into synthetic-population claims. Each image was visually reviewed; use its art direction rather than treating every generated detail as authoritative.

Colours here are explorations for illustrations and decorative surfaces, not replacements for club/party identity, chart colours or semantic status colours. Test selected colours in the real interface before adopting them. These images vary both drawing style and colour and are not a controlled palette-only comparison.
