# Estimador launch: rough brand directions

Generated concept boards, not final logo artwork. The existing website branding has not been replaced.

| Direction | Character | Main opportunity | Refinement needed |
| --- | --- | --- | --- |
| 01 — Território | Calm, geographic, editorial | Closest visual relationship to the living atlas; contour ribbons can animate as the camera moves | Make the symbol less like a generic wave/globe and strengthen the lowercase e |
| 02 — Mosaico | Warm, modular, playful | A flexible Portuguese-inspired visual language for cards, data stories and motion | Refine the tile arrangement so the mark feels more distinctive than a pie chart |
| 03 — Perspetiva | Confident, editorial, precise | A point inside a range connects naturally to the name estimador and works across all subjects | Refine bracket proportions and letter spacing; test the favicon without colour |

Suggested next direction: develop Perspetiva as the core identity, with the warmth and modular illustration language of Mosaico in the wider design system. Keep the logo itself simple.

Shared palette: ivory, deep pine, sage, butter yellow, faded terracotta and powder blue. All mockup statistics and supporting copy are illustrative.

Generated with the built-in image-generation tool. Original generation prompts are in `prompts.json`. A second editing pass preserved the compositions while replacing the dark, low-contrast backgrounds with ivory and removing glow and shadow effects. The Perspetiva statistics caption was changed to “EXEMPLO ILUSTRATIVO”.

The next design stage should redraw the selected mark as vector artwork, refine typography, and test at header and favicon sizes. These boards are for choosing a direction.
