LER COM CONTEXTO

Uma previsão não é um resultado.

Uma previsão expressa o que podia acontecer com a informação disponível. O resultado é o que foi apurado na eleição.

Como ler um intervalo?

Para a mesma medida, escala e nível de cobertura, um intervalo mais largo expressa maior dispersão dos valores estimados. A largura, por si só, não demonstra a qualidade de um modelo.
