These are visual prototypes. Numbers, dates, sources, bylines and prose are illustrative, not verified reporting. The generated map is not an authoritative geographic asset. Implementation must retain the existing CAOP geometry, continuous zoom, release boundaries and actual data. Do not add the generated satellite toggle or replace the continuous map with an inset.

The written proposal takes precedence over generation variations: dashboard prose remains sans-serif, numerical panels remain neutral, current club/party colours are preserved, and actions must not imply unavailable data. Keyboard focus, responsive layouts and contrast require implementation testing; this board alone does not validate them.
