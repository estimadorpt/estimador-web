# Round 2 — website-oriented variations on the illustrated magazine

Static visual prototypes. No changes to the site.

- 2A: equal-weight product grid. Four clear entry points with bounded illustrations.
- 2B: featured population workspace and football rail; economy and elections below. Recommended balance of website usability, scientific positioning and expressive illustrations.
- 2C: illustrated subject selector with one shared interactive preview. Strongest application concept; needs care not to hide the other subjects behind a default population view.

Generated copy, controls and metrics are provisional. In particular 2A incorrectly labels 55% as a next-match win probability; the intended snapshot is title probability. 2B's bottom match result is invented placeholder copy and must not be published. 2C's distribution is an illustrative placeholder, not population data. No claims of working controls, validated distributions, current results or available microsimulation follow from these image prototypes. Retain the existing approved logo in implementation.
