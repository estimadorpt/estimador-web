# Page-specific illustration direction

These static prototypes explore the three non-population sections in the established warm illustrated style. They are not deployed designs or working tools. Built-in image generation was used; prompts accompany the images.

## The correction

Simplify incidental detail, not the contextual clues that identify the subject. Three seats could be a cinema. A generic arch could be any entrance. Neither is an adequate stand-alone election or football symbol. Use a compact scene when context matters, a conventional labelled icon for controls, and no illustration when neither adds value.

The guiding table was proposed by the assistant and endorsed by the user:

| Keep | Reconsider | Avoid |
| --- | --- | --- |
| Frontal architecture and small architectural fragments | How people are drawn | Generic friendly characters as the main brand signature |
| Paper, pine and selective colour | The muted palette’s lack of contrast | Assuming a palette change creates originality |
| Different expression levels across page types | How much imagery each page needs | Adding illustration merely to fill space |

## What the three images test

1. **Economy:** an explanatory page with a distinct question and a paused-state layout. The illustrative inflation lesson and proposed topic navigation are concepts, not a claim that these articles/tools already exist.
2. **Football:** a working-area-first layout where interaction gives the page its playful character. Generic teams and blank comparison values deliberately avoid inventing a forecast. The image does not implement any calculation.
3. **Elections:** archive chronology and different institutions make the page specific. Ballot plus privacy screen provides context that three isolated seats cannot. The presidential and parliamentary facades are illustrative, not architectural references.

## Size is not the only simplification

At a section entrance, allow a compact 160–240px vignette to carry two or three identifying cues. At 40–64px, use only artwork that remains recognisable with its visible text label. Below that, use ordinary interface icons or omit the image. Recompose artwork for small sizes rather than scaling a whole scene. Do not measure final CSS from generated mockup pixels.

The scenes can share palette, proportions, edge treatment, shallow depth and human warmth while differing in content. Architecture is a supporting vocabulary, not a rule that every topic must be represented by a building.

## Implementation boundary

Keep the existing logo, fonts, components, accessibility and actual data status. Generated page copy is exploratory, not fact-checked publication text. No fabricated figures, forecasts, sources or unimplemented capabilities should be copied into the site. Use semantic labels beside images. Keep raster scene art separate from HTML text, controls and charts. Test mobile compositions and actual small-size assets after a direction is selected. No site implementation or deployment is part of this pass.


## Visual review

All three generated images were visually reviewed; file headers/dimensions and prompt count checked. The subjects are now recognisable without relying on isolated ambiguous symbols. The different page structures are the stronger contribution: economy explanation with a methods rail, football choices beside comparison, elections as a dated archive.

The generated headers remain larger than intended, especially on the simulator. Use the compact dimensions in this brief in any subsequent implementation, not the literal mockup proportions. Omit the repeated football image beside methodology. Economy needs only one methods action rather than the two shown in its sidebar. Generated shop and polling-place slogans are not approved copy. Do not copy their incidental text. The archive institutions are stylised suggestions and require actual architectural reference if claiming to depict specific buildings. The illustrative uncertainty comparison should use the same neutral colour and scale for both examples, with the intended coverage stated in any real explanation; avoid implying green is better or more reliable. The football comparison must specify its metric (e.g. expected points or championship probability) and compute values using real supported simulator logic before becoming a product. Its generic blank table is an initial-state layout study, not a completed result view.

These are desktop concept images. Mobile layouts, interactions, destinations and data behaviour have not been built or tested. No site code or production assets were changed.
